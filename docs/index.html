LociiGhost

iPhone GPS 模擬工具 —— Apple Silicon 原生 macOS app。

v1.9.4 準備發佈中

核心功能完成：多手機獨立控制、per-device 路線記憶、雙裝置同步、 SwiftData 持久化、繁中／英雙語、六種移動模式、GPX 匯入、書籤。

公開的可下載二進位等候 Apple Developer ID 證書與 notarization 程序完成後釋出，避免使用者打開 .app 時被 Gatekeeper 擋下。
