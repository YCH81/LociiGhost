LociiGhost

iPhone GPS 模擬工具 —— Apple Silicon 原生 macOS app。

v1.15.0 已發佈

發布日期：2026-06-17。 (1) 路線播放新增「從哪裡開始」三選一 — 點側邊欄的路線跑出來的 sheet 多了一欄：從頭開始、從上次中斷處繼續（#N）、或指定第 N 個點開始。AppState 每 2 秒記錄一次進度，Stop 後重開 sheet 預設選 Resume；自然走完則清零。 (2) 修復長 GPX 路線匯入後 app 卡死 — 1163 點之前要等 1-2 分鐘才能看到地圖；現在 stop pin 超過 100 點時自動縮點（保留 #1 + 終點 + 每 101 一個），渲染量 1163 → ~12 顆，daemon 仍收到完整 stops。MKMapView 拉遠時 badge 改成小色點。 完整變更紀錄見 v1.15.0 release notes。

DMG 已通過 Apple Developer ID 簽名 + Apple notarize， 雙擊即可開啟，不會被 Gatekeeper 擋下。請務必用 DMG 安裝， 不要把 .app 解壓到 iCloud 同步的資料夾（Documents、Desktop）， iCloud File Provider 會蓋上額外 xattr 把簽章弄壞，導致顯示「damaged」。

Intel 版 x86_64 · macOS 13+ · 不再更新

⚠️ 這版不會再做維護。能用就能用、不能用就不能用。 未來主版的新功能、bug fix 不會回推到 Intel 版； Intel 端如果出現新 bug 也不會修。下載前請理解這是一次性釋出。

主版只支援 Apple Silicon (M 系列) + macOS 14+。 如果你是 Intel + macOS 13，可以下載這版試試看。 怎麼確認：點左上角 → 關於這台 Mac， 看到「Apple M…」用主版、看到「Intel Core…」才考慮這版。
