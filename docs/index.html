發布日期：2026-05-14。6 個修復一次出： 「還原真實 GPS」改用 fresh CoreLocation fix 飛回 Mac 當下位置； WiFi 裝置列表多 IP 路徑不再撞同名；支援匯入 LocWarp 路線 JSON； Settings 的 Routes Import/Export 結果直接在 sheet 內顯示； 導航 ETA 面板拆三行平鋪；新增 Scripts/test-clean-install.sh 防 v1.10.0–v1.10.4 cascade 重演。 完整變更紀錄見 v1.10.6 release notes。

DMG 已通過 Apple Developer ID 簽名 + Apple notarize， 雙擊即可開啟，不會被 Gatekeeper 擋下。請務必用 DMG 安裝， 不要把 .app 解壓到 iCloud 同步的資料夾（Documents、Desktop）， iCloud File Provider 會蓋上額外 xattr 把簽章弄壞，導致顯示「damaged」。
