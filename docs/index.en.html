v1.13.0 Released

Released 2026-05-28. (1) Bookmark system overhaul — bookmarks can carry photos (just add image_url to your import); the photo window dismisses on click-outside, no need to hit X. Manager panel (sidebar gear) supports multi-select bulk delete / move / prefix-suffix; categories can be renamed, merged, or deleted. Sidebar search filters as you type. Layer picker has a new "Show bookmarks on map" toggle that paints indigo pins on the map with auto-clustering at low zoom. (2) Pan-after-teleport is much smoother — Apple map layers switched to SwiftUI's native Map component; OSM / Carto / ESRI keep their existing rendering path. (3) Status-bar chips refresh during route playback — country flag / weather / remote-time now follow the moving simulated location in real time instead of freezing. (4) Large bookmark imports no longer freeze the UI — 3 000+ bookmarks go from a multi-second hang to instant. See v1.13.0 release notes for the full changelog.

The DMG is Apple-Developer-ID-signed and notarised, so it opens with a double-click without a Gatekeeper warning. Use the DMG, not a zip: extracting a signed .app into an iCloud-synced folder (Documents, Desktop) lets the File Provider attach extra xattrs that break the signature and show "LociiGhost is damaged".
