LociiGhost

iPhone GPS spoofing tool — Apple-Silicon-native macOS app.

v1.9.4 Preparing release

Core feature set complete: multi-phone independent control, per-device route memory, dual-device sync, SwiftData persistence, Traditional Chinese + English UI, six movement modes, GPX import, bookmarks.

A signed, downloadable binary will be published once Apple's Developer ID certificate and notarization clear, so users don't hit a Gatekeeper warning when opening the .app.
