## 1. LociiGhost 是什麼

LociiGhost 是一款 macOS app，它能把你 iPhone 的 GPS 位置「換成你指定的地點」。在 Mac 上選一個地點，iPhone 馬上就會以為自己在那裡 —— iPhone 上所有看位置的 app（地圖、健身、社群、遊戲⋯⋯）也都會跟著改。

**適合的用途：**
- 開發人員測試 app 的定位功能（不用真的跑到別的城市）
- 測試外送、共乘、地圖相關 app 的行為
- 個人的地圖探索、GIS 研究
- 預覽某個地點在 iPhone 上看起來如何

**不適合的用途：**
- 用在違反 app 服務條款的場合（例如某些定位類遊戲）。這類用途**可能會讓你的帳號被永久停權**，請見[第 2 節警告](#2-使用前須知)。

## 2. 使用前須知

### 硬體需求
- **Mac**：Apple Silicon（M1 / M2 / M3 / M4 系列）。**Intel Mac 不支援**，這是設計上的限制，不是 bug。
- **iPhone**：任何可以用 USB 線連上 Mac 的 iPhone 都可以。iOS 17 以上需要額外開啟 Developer Mode（第 5.2 節會說）。

### 系統需求
- **macOS**：14 Sonoma 以上。詳細相容性對照表請參考 [compatibility.md](compatibility.md)。

### 重要警告（請務必讀完）

> **使用 LociiGhost 可能違反某些 app 的服務條款。**
>
> 在某些 app 上使用模擬定位（特別是定位類遊戲、考勤打卡、共乘平台等），可能會觸發伺服器端偵測，導致：
>
> - **帳號永久停權**
> - **遊戲進度永久消失**
> - **平台禁用裝置 ID**
>
> LociiGhost 本身是中性的學術開發測試工具。**所有使用後果由使用者自行承擔。** 完整免責聲明見 [第 12 節附錄](#12-附錄)。

## 3. 第一次安裝

### 下載
到 GitHub Releases 頁面下載最新的 DMG：

👉 **https://github.com/YCH81/LociiGhost/releases**

選最上面那個版本（例如 `LociiGhost-v1.10.0.dmg`），點下載。

### 安裝
1. 雙擊下載下來的 `.dmg` 檔案，會跳出一個 Finder 視窗
2. 把裡面的 **LociiGhost.app** 拖到右邊的「應用程式」資料夾
3. 從應用程式資料夾打開 LociiGhost

### 第一次開啟時可能跳的警告

第一次打開時，macOS 可能會跳出：

> **「無法打開 LociiGhost」 — 因為無法驗證開發者**

如果跳了，這樣做：

1. 在 Finder 的「應用程式」資料夾找到 LociiGhost
2. **按住 Control 鍵 + 點一下** LociiGhost（或右鍵）
3. 選「**打開**」
4. 對話框會多一個「**打開**」按鈕，點下去
5. 之後再開就不會跳了

> v1.10.0 之後的版本已經做了 Apple Notarization，正常情況下不會跳這個警告。如果還是跳了，就照上面流程走一次。

**1. 確認語言**

**2. 允許 Mac 取得位置（系統會自動跳）**

第一次開啟時，macOS 會問「LociiGhost 想取得你的位置」—— 點「允許」。
這只是讓地圖能定位到你目前位置當作起始點，不會把你的位置傳給任何人。

## 5. 連接你的 iPhone（第一次）

第一次連線**強烈建議用 USB 線**。WiFi 連線需要先用 USB 配對過一次才能用。

### 5.1 USB 連線（第一次必做）

1. 用 USB 線把 iPhone 接到 Mac
2. iPhone 螢幕會跳一個對話框：「**信任這部電腦？**」
3. 在 iPhone 上點「**信任**」，然後輸入 iPhone 的密碼
4. 等幾秒鐘，LociiGhost 左側邊欄會出現你的 iPhone（旁邊有 USB 徽章）

如果側邊欄沒出現 iPhone，請看[第 11 節疑難排解](#11-常見問題與疑難排解)。

### 5.2 開啟 Developer Mode

Apple 要求要在 iPhone 端開啟 Developer Mode 才能用模擬定位功能。

**在 iPhone 上操作：**

1. 設定 → 隱私權與安全性
2. 拉到最下面找到「**Developer Mode**」
3. 打開開關
4. iPhone 會要求重新啟動，照做
5. 重啟後，iPhone 會再跳一個確認對話框，點「**打開**」並輸入密碼

> 沒看到 Developer Mode 選項？通常是因為 iPhone 還沒被任何 Mac 認過。先做完 5.1 USB 連線那步，把 LociiGhost 開著，再去 iPhone 設定裡找 Developer Mode。

LociiGhost 也有一個按鈕能幫你跳到 iPhone 的這個設定畫面：點側邊欄裝置旁邊的「**開啟 Developer Mode…**」即可。

### 5.3 授權 LociiGhost（一次 Touch ID）

iOS 17 以上的裝置第一次連線時，LociiGhost 頂部會出現紅色橫幅：

> **「需要授權」** —— 點右邊的「授權」按鈕

點下去之後：

1. 跳出 macOS 系統的 Touch ID 對話框
2. 按指紋（或輸入 Mac 密碼）
3. 橫幅消失，授權狀態變綠

**這個動作每次重啟 Mac 才需要做一次**，不是每次開 LociiGhost 都要做。重開 app 不用重新授權。

> 為什麼要授權？LociiGhost 需要 Mac 的權限才能跟 iPhone 通訊，這是 iOS 17 以後 Apple 的規定。

### 5.4 之後想用 WiFi 連線（不用線）

USB 連得起來之後，可以改成 WiFi 連線，就不用一直插線了。

設定方式：點側邊欄裝置旁邊的選單 →「**WiFi 配對**」，跟著畫面提示走一次（會跳兩次「信任這部電腦」對話框）。配對完成之後，下次就可以不插線直接 WiFi 連。

詳細 WiFi 連線教學請看 → **[wifi-setup.md](wifi-setup.md)**

## 6. 跑你的第一條路線

### 最快驗證：瞬間移動到一個地點

1. **在地圖上找一個你想去的地方**（例如東京車站、紐約時代廣場）
   - 直接在地圖上拖曳、放大縮小找
   - 或在頂部「搜尋地址」搜尋
2. **點一下地圖上那個位置**
   - 地圖上會出現一個藍色 pin
   - 同時跳出「瞬間移動 / 導航」的浮動面板
3. **點「瞬間移動」**
4. **拿起 iPhone**，打開「地圖」app
5. iPhone 的位置**就會變到你選的地方**

> P.S 如果點選 **還原功能**：⏱️ iPhone 的 GPS 重新校準需要 **30 秒到 2 分鐘**。如果一開始看到還是原本的位置，等一下就好。

### 接下來：模擬「移動」

瞬間移動只是「換位置」，不是「走過去」。
如果你想模擬從現在的位置慢慢走/開車過去：

1. 重複上面 1–2 步，在地圖上選目的地
2. 浮動面板上選「**導航**」
3. 在底部列選交通方式：**🚗 汽車 / 🚲 單車 / 🚶 步行**
4. 拉「速度」滑桿到你想要的時速
5. 按「**開始**」
6. 看著地圖上的 iPhone 圖標沿著規劃出來的路線慢慢移動

播放中你可以隨時拉速度滑桿，速度會即時變、ETA 也會跟著重算。

## 7. 六種移動模式

打開側邊欄的「移動模式」區，你會看到這幾個選項：

| 模式 | 用途 | 適合場景 |
|---|---|---|
| **瞬間移動** | 把 iPhone 位置瞬間換成某一點 | 最常用、最快驗證 |
| **導航** | 規劃路徑、依速度模擬移動 | 測試導航 / 外送 / 共乘 app |
| **路線循環** | 同一條路徑跑 N 圈 | 長時間放置測試、模擬巡邏 |
| **多點** | 經過多個停靠點，每點停一段時間 | 模擬上下班、外送多單配送 |
| **隨機漫步** | 在某個範圍內隨機亂走 | 模擬「在某區域活動中」 |
| **搖桿** | 用鍵盤方向鍵或螢幕搖桿手動控制 | 即時互動測試 |

外加一個遊戲專用模式：

- **拉金盆（Gold Ditto）** — 玩家專用，模擬特殊移動模式。一般使用者用不到。

### 各模式怎麼用

**瞬間移動** — 已在第 6 節示範。最簡單，點地圖然後點瞬間移動就好。

**導航** — 也在第 6 節示範。可以一次加多個經過點：點地圖選第一個點，再點地圖選第二個點，LociiGhost 會自動把它們排成路線。

**路線循環** — 在多點模式或從匯入的路線設定「圈數」（Laps），可以跑 1–99 圈。

**多點** — 點側邊欄「多點」進入模式，在地圖上依序點要停的地方。每點可以設定停留時間。最後一鍵開始，iPhone 會依序到每個點、停、再到下一個。

**隨機漫步** — 點側邊欄「隨機」進入模式，設定範圍（半徑）跟步數，按開始，iPhone 會在範圍內隨機晃。

**搖桿** — 點側邊欄「搖桿」啟動，之後可以用鍵盤方向鍵推 iPhone 往各方向移動，或用螢幕上的搖桿圖控制。適合需要邊測邊看 app 反應的場景。

## 8. 路線與書籤

LociiGhost 把常用地點分兩種：**書籤**（一個點）跟**路線**（一條路徑）。

### 書籤：一鍵跳到常去的地點

**新增書籤：**
1. 在地圖上你想存的地方**按住 Control + 點一下**（或右鍵）
2. 選單選「**儲存為書籤…**」
3. 取個名字，按儲存

**使用書籤：**
- 側邊欄「書籤」區會列出所有書籤
- 點書籤右邊的「瞬移到這裡」按鈕，iPhone 馬上跳過去

**批次匯入書籤：**
如果你從 LocWarp 或其他工具匯出過 JSON 格式的書籤，可以一次貼上：書籤區的選單 →「**從 JSON 匯入書籤**」→ 把 JSON 內容貼進去。

### 路線：儲存完整路徑供日後重播

**匯入 GPX 路線：**
1. 主選單「**檔案 ▸ 匯入 GPX…**」（或按 `⌘O`）
2. 選一個 `.gpx` 檔案
3. 路線會出現在側邊欄「路線」區

**匯出目前路線：**
1. 規劃好一條路線後，主選單「**檔案 ▸ 將目前路線匯出為 GPX…**」（或按 `⌘E`）
2. 存成 `.gpx` 檔，可以分享給別人或之後重用

**重播路線：**
側邊欄「路線」區，點任一條路線，會跳「瞬移到起點並依序走完路線？」確認框 → 確定後開始播放。

**把多點存成路線：**
在多點模式裡擺好所有停靠點之後，點「**加入新路線**」就能存成路線，下次直接重播這趟行程。

## 9. 進階：用手機遙控 Mac

人不在 Mac 旁邊也想換位置？LociiGhost 有手機網頁端，可以在 iPhone 上開瀏覽器直接控制 Mac。

### 設定流程

**在 Mac 上：**

1. 側邊欄找到「手機操控」按鈕，點開
2. 視窗會顯示：
   - 一個網址，類似 `http://111.168.2.5:8779/phone`
   - 一個 6 位數的 PIN

**在 iPhone 上：**

3. 確認 iPhone 跟 Mac 在**同一個 Wi-Fi**
4. 用 Safari 打開那個網址
5. 輸入 PIN
6. 進入手機操控介面

### 手機端能做什麼

- 搜尋地點 → 瞬間移動或導航
- 從書籤一鍵跳轉
- 即時調整速度
- 開始 / 暫停 / 停止移動中的路線

### 安全注意事項

- **PIN 每次 daemon 重啟都會換新的**，重啟 Mac 之後要回到 LociiGhost 看新的 PIN
- 想立刻把所有已配對的手機踢掉？點「**重新產生 PIN**」即可
- 多支手機可以同時連，但同一時間只有一支能控制目前選中的 iPhone

## 10. 速度控制與地圖路徑引擎

### 速度滑桿

底部列的「速度」滑桿可以拖到 0–200+ km/h。**移動中也能即時拉**，速度會立刻變、預估到達時間（ETA）也會跟著重算。

### 圈數

如果要讓同一條路線跑多圈，可以在路線播放面板設定「圈數」（Laps），最多 20 圈。

### 路徑引擎（要算路線時用哪個地圖服務）

導航模式會自動規劃路線。LociiGhost 提供四種引擎選擇（⚙️ 設定 →「路徑引擎」）：

| 引擎 | 特色 | 適合 |
|---|---|---|
| **Apple 地圖**（預設） | 免設定、台灣資料佳、原生整合 | 大多數情境 |
| **OSRM 公開 demo** | 免費、單車路網真實 | 想要單車真實路徑、不在意速度 |
| **Google Directions** | 路徑品質高、全球都好 | 要自己申請 Google API key |
| **直線模式** | 不規劃道路、兩點之間直線連 | 室內、無路網區域、測試用 |

一般使用者用預設（Apple 地圖）就好，不用改。

## 11. 常見問題與疑難排解

### 安裝相關

**Q: 第一次打開 app 跳「無法驗證開發者」怎麼辦？**
A: 用 Control + 點（右鍵）→「打開」開一次就好。詳見[第 3 節](#3-第一次安裝)。

**Q: 我的 Mac 是 Intel CPU，能用嗎？**
A: 不行。LociiGhost 只支援 Apple Silicon（M1/M2/M3/M4）。

### 連線相關

**Q: 側邊欄一直看不到我的 iPhone？**
A: 依序檢查：
1. USB 線好的嗎？換條線試試
2. iPhone 上有沒有點過「信任這部電腦」？沒有的話，把線拔掉再插一次
3. iOS 17 以上有沒有開 Developer Mode？（第 5.2 節）
4. 試試重開 LociiGhost

**Q: 頂部一直紅色「需要授權」？**
A: 點「授權」按鈕，用 Touch ID 通過一次。每次重啟 Mac 之後第一次連 iOS 17+ 裝置都要做一次。

**Q: WiFi 連線連不上？**
A: 確認 iPhone 跟 Mac 在同一個 Wi-Fi。公共 Wi-Fi（咖啡廳、飯店）可能會擋 P2P 流量 —— 改用 USB 或開 iPhone 的個人熱點分享給 Mac，這個一定通。完整 WiFi 教學見 [wifi-setup.md](wifi-setup.md)。

### 使用相關

**Q: 點了瞬間移動，但 iPhone 上位置沒變？**
A: 等 30 秒到 2 分鐘。iPhone 的 GPS 重新校準需要時間，這不是 bug。

**Q: 路線跑到一半停住了？**
A: 通常是 iPhone 螢幕鎖太久，把 iPhone 喚醒，連線會自動恢復。如果沒有，回 LociiGhost 看授權狀態，需要的話重新授權。

**Q: 想完全停止模擬，讓 iPhone 回到真實位置？**
A: 在 LociiGhost 內按停止鍵就會停止模擬，或者是選擇按還原鍵。執行後約莫30-2分鐘內會還原，最徹底的方式：重啟 iPhone，所有模擬資料都會清掉。

**Q: 我能同時控制多隻支 iPhone 嗎？**
A: 可以。各自連好之後，側邊欄會列出兩支，點哪支就在控制哪支。每支 iPhone 的路線、書籤、目前狀態都是獨立的，切來切去不會搞混。

**Q: 設定的位置會傳給 Apple、Google 或其他人嗎？**
A: 不會。LociiGhost 完全在本機運作，不上傳任何位置資料。

### 進階

**Q: 我用 Pokémon GO / 寶可夢 / Pikmin 等遊戲會不會被封號？**
A: 有可能。請見 [第 2 節警告](#2-使用前須知)。**自行承擔風險**。

**Q: 安卓手機能用 LociiGhost 嗎？**
A: 不行，LociiGhost 只支援 iPhone。
