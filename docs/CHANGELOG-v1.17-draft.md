## 使用者看得到的改動

### 花農專用模式

繞著每個途經點走小圈，一圈接一圈。可設繞圈半徑、每圈幾站（3–20）、每點幾圈
（0.5 步進，半圈會停在圓的另一側，通常正好是下一個點的方向）、總共跑幾輪、
到站前後各等多久、每一站停多久，以及點與點之間要用走的還是瞬移。

途經點就是多點模式那份清單，地圖上點一下就是加一個點——不會有兩份各自為政的
清單，也不用因為先開了哪個面板而重建一次路線。面板下方的預估總時長是跟 daemon
要的，不是 App 自己再算一遍：產生路線的程式和報時間的程式是同一份，所以「說要跑
兩小時」和「實際跑兩小時」不會分岔。

斷線會自動接回去繼續跑（只有花農模式這樣做——它就是掛在那邊磨的功能，進度也只是
一個步數；其他模式的路線狀態在 Mac 這邊，安靜地自己重啟比讓你按一下更糟）。

手機遙控也能開：沒選點就繞 iPhone 現在站的位置，三根滑桿（半徑、圈數、輪數）。

### 每站隨機停頓

原本每站停固定秒數。固定的東西是最好認的特徵——沒有人會連續十二次都剛好停 8 秒。
現在是一個範圍（預設 5–20 秒），每一站在範圍內重抽。設定成上下限相同就是舊行為。

### 三裝置群組同步

多支 iPhone 一起跑同一段。預設完全同座標；也可以給某支一個距離＋方位的偏移。
瞬移、導航、隨機漫步、花農全部支援——扇出做在所有移動模式共用的定位服務裡，
所以不是「四個模式各支援一次」，而是它們根本不知道有群組這回事。

主機（你選的那支）失敗會停止整段；副機推送失敗就把它踢出群組、其他支繼續——
三支手機因為其中一支被拔掉而全停，不是你要的。開始時沒連上的成員會被跳過並提示。

### 地址搜尋四家可選

Apple／Nominatim（OpenStreetMap）／Photon（komoot）／Google。Apple 仍是預設：
只有它有真正的逐字自動完成，而且不用金鑰、沒有額度。兩家 OSM 服務補的正是 Apple
索引得最差的中文店名與地標；Google 最準但用你自己的金鑰、每次搜尋算你的錢。

Nominatim 的使用條款是每個來源每秒一次，而且明文禁止拿公開 endpoint 做逐字自動
完成，所以選它時輸入停下來才會送出——那不是效能調校，是能不能用它的條件。

### 收藏可以匯出成 GPX

`.gpx` 的 `<wpt>` 是每個地圖 App 都讀得懂的格式（Garmin Connect、Gaia、Organic
Maps、Google Earth，macOS 的預覽也行）。分類、圖示、照片連結都走 GPX 的標準欄位，
所以別人的檔案匯進來是一般收藏，我們的檔案在別的 App 打得開。原本的 JSON 匯出
保留，那是 LocWarp 交換用的格式。

顏色只有你手動選過的才會寫進檔案：自動配色是用固定演算法從分類名稱算出來的，
每台機器結果都一樣，寫進去反而會在匯入時把它們全變成手動指定。

### 分類顏色自訂 + 六款花形地圖釘

側邊欄與地圖釘可以指定分類顏色，沒指定的會從分類名稱算一個穩定的顏色（同一個
分類在任何一台機器、任何一次啟動都是同一色）。地圖釘另外可以選六款花：雛菊、
櫻花、鬱金香、向日葵、酢漿草、梅花。六種形狀乘十種顏色，三千個釘子也還分得出來。

### Cooldown 防偵測閘門

由你設定的物理合理性規則：一個「最快合理速度」，加上「任何跳躍之間的最小間隔」。
兩個位置之間的距離除以速度，就是下一次跳躍最早可以送出的時間；還沒到就擋下來，
並顯示還要等幾秒。

預設關閉——會默默延後瞬移的東西，必須是你知情下打開的。它只擋跳躍（瞬移、各模式
的起跳），不會打斷跑到一半的路線：連續移動本來就受速度限制。桌面和手機遙控走的是
同一份設定，不會出現「桌面擋、手機不擋」。

## 內部（不影響操作，但值得記一筆）

- 隨機漫步和花農模式共用同一個位移迴圈。兩份手寫的計時迴圈一定會分岔——一份會在
  終點多走幾公分，乘上二十個頂點、五十圈，圈就會慢慢螺旋出去。
- 花圈的幾何用球面公式，不是「除以 111 公里再除以 cos(緯度)」那套近似。後者在
  北緯 70 度的 100 公尺圈上差 17 公分，一個晚上要走幾百圈的圓不該是橢圓。
- 手機遙控頁新增靜態檢查：腳本抓的每個元素 id 都存在、每個字串兩種語言都有。
  這兩種錯都是靜悄悄的——一個在沒人看的事件處理器裡爆掉，一個對另一種語言的
  使用者顯示 key 名稱。
- 修掉手機端四處會把錯誤內容直接丟給提示框的地方：cooldown 拒絕回的是物件不是
  字串，原本會顯示「[object Object]」，多點導航那個還會直接丟例外、什麼都不顯示。
